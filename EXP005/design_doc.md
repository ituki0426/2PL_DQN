# DQNの実データ実験 設計書

## 1. 目的

実際の受験者–項目反応データを用いて、DQNによるCAT項目選択手法の性能を評価する。

シミュレーション実験ではIRTモデルから回答を確率的に生成していたが、本実験では方策が選択した項目に対する実際の0/1回答を回答行列から取得する。

本実験は、全受験者を用いて事前推定した項目パラメータを使用する予備的な実データ実験と位置づける。したがって、未知の集団への完全な外的妥当性を検証する実験ではなく、固定済み項目バンク上での手法比較を目的とする。

## 2. ベース実験

実装はEXP001をベースとする。

EXP001から次の要素を引き継ぐ。

- CAT中の能力推定：MLE＋Dodd規則
- 項目選択規則：MFI、FIWL、MPWI、MEPV
- DQNの状態、報酬、ネットワーク構造
- リプレイバッファと学習処理
- 既存手法と提案手法の構成
- テスト長と評価ステップ
- 結果の集計形式

既存のEXP001は変更せず、実データ実験用の独立した実験パッケージとして実装する。

## 3. 使用データ

実データは `data/` 以下に保存する。

対象データセットは次の3種類とする。

- `choi_2026_cmsce_2019_2`
- `choi_2026_cmsce_2020_1`
- `choi_2026_cmsce_2021_2`

各データセットは独立した項目バンクとして扱う。年度間で項目パラメータ、能力尺度、DQNモデルを共有しない。

使用するデータセットはコマンドライン引数 `--dataset` で指定する。

```sh
python run_grid.py \
  --experiment EXP005 \
  --dataset choi_2026_cmsce_2019_2 \
  --rep 1
```

各データセットのディレクトリには、少なくとも次のファイルが必要である。

| ファイル | 内容 |
|---|---|
| `item_parameters.csv` | 項目ID、識別力、困難度 |
| `person_scores.csv` | 受験者ID、全項目回答に基づくEAP推定値 |
| `responses.csv` または対応するwide CSV | 行が受験者、列が項目の0/1回答行列 |

読み込み時には次を検証する。

- `person_scores.csv` と回答行列の受験者IDが一致する
- `item_parameters.csv` と回答行列の項目IDが一致する
- 項目順を項目IDに基づいて明示的に整列する
- 受験者IDと項目IDを文字列として読み込む
- 回答値が0または1である
- 受験者IDと項目IDに重複がない
- CATのテスト長以上の利用可能項目が存在する

初回実装では欠損回答をサポートせず、回答行列に欠損があった場合はエラーで停止する。

## 4. 項目パラメータ

本実験では、各データセットの全受験者を用いて推定済みの `item_parameters.csv` を使用する。受験者分割後の項目パラメータ再推定は行わない。

この設定では、テスト受験者の回答も項目パラメータ推定に使用されている。そのため、結果には次の制約がある。

- 項目パラメータが未知の新規データへの汎化性能ではない
- 固定済み項目バンク上での方策間比較である
- テストデータから完全に独立した評価ではない

この制約を結果および論文中に明記する。

### CAT候補項目

識別力が非正の項目はCAT候補から除外する。

```text
a <= 0
```

負の識別力でも情報量の計算では `a²` によって正の値になるため、そのまま含めるとMFIなどが不適切な項目を選択する可能性がある。

識別力によるスクリーニング後、各データセットの困難度が小さい15項目と大きい15項目をCAT候補から除外する。困難度が同じ項目は項目ID順で順位を決め、各側ちょうど15項目を除外する。追加の感度分析として、次のスクリーニングを行い、その後に同じ困難度除外を適用する。

```text
a >= 0.2 かつ |b| <= 4
```

項目を除外した後は、項目パラメータ、回答行列、DQNの出力層、使用済み項目マスクを同じ項目順で再構成する。

## 5. 受験者の分割

各データセット内の受験者を次の3群に分割する。

- 学習用：70%
- 検証用：10%
- テスト用：20%

`theta_EAP` の十分位を用いた層化分割により、各群の能力分布を可能な限り揃える。

分割用乱数種はDQNの学習用乱数種から分離する。反復ごとに分割を切り替え、反復kの分割用乱数種は基準値 `split_seed` に対して `split_seed + k - 1` とする。同一反復内では全手法が同じ受験者分割を使用する。

```text
split_seed = 20260904        # 基準値
split_seed_k = split_seed + k - 1  # 反復kで使う分割用乱数種
```

各群の役割は次のとおりとする。

| 群 | 用途 |
|---|---|
| 学習用 | DQNの遷移生成とパラメータ更新 |
| 検証用 | 学習途中のQネットワークの選択 |
| テスト用 | 最終的な性能評価のみ |

同一受験者が複数の群に含まれることを禁止する。

## 6. 実回答を用いたCAT環境

シミュレーション実験では、受験者の潜在特性値とIRTモデルから回答を確率生成していた。

実データ実験では回答生成を行わず、選択された受験者と項目に対応する実回答を回答行列から取得する。

1エピソードは1受験者のCAT受検に対応する。

```text
1. 受験者を学習データから選択する
2. 初期能力推定値を設定する
3. 方策が未使用項目から項目を選択する
4. 回答行列からその項目の実回答を取得する
5. 回答履歴から能力推定値と状態を更新する
6. 遷移をリプレイバッファへ保存する
7. テスト長に達するまで3〜6を繰り返す
```

回答取得は概念的に次の処理となる。

```python
response = response_matrix[respondent_index, item_index]
```

同一受験者を別エポックで再利用した場合、同じ項目に対する回答は常に同一である。ただし、探索およびQネットワークの更新により、選択される項目系列はエポック間で異なり得る。

この実験は、元の試験で観測された回答が、CATにより項目提示順序を変更しても変化しないと仮定する。

## 7. 初期能力推定値

EXP001では、回答前の能力推定値を受験者ごとに `U(-0.5, 0.5)` から生成している。

実データ実験では、受験前に利用可能な個人情報を仮定しないため、全受験者の初期能力推定値を0とする。

```text
theta_hat_0 = 0
```

MLEが計算できない全問正答・全問不正答の途中履歴については、EXP001と同じDodd規則を適用する。

## 8. エポック制

既存の `n_episodes` は廃止し、学習量を `n_epochs` で指定する。

`DQNConfig` に次の設定を追加する。

```python
n_epochs: int = 5
```

既定値は5エポックとする。

1エポックでは次の処理を行う。

1. 学習受験者のインデックスをシャッフルする
2. 学習受験者を全員1回ずつ使用する
3. `n_env` 人単位で並列にCATを実行する
4. 各回答後に遷移を保存し、DQNを更新する

学習受験者数が `n_env` で割り切れない場合も、最後の不完全なバッチを破棄せず使用する。実装は可変バッチサイズに対応させる。

既存手法と提案手法の両方に同じ `n_epochs=5` を適用する。したがって、両条件が利用する受験者エピソード数は同一となる。

両条件の `n_env` は32とする。EXP001の既存条件では `n_env=1` だったが、全学習受験者を5 epoch使用するEXP005でこれを維持すると、既存条件だけが提案条件の約32倍の勾配更新を行う。EXP005では並列単位を揃えることで、同じエピソード数に対する更新回数と実行時間を条件間で同程度にする。

総エピソード数は次式で決まる。

```text
総エピソード数 = 学習受験者数 × n_epochs
```

総遷移数は次式で決まる。

```text
総遷移数 = 学習受験者数 × n_epochs × テスト長
```

## 9. 参照能力値

シミュレーション実験では潜在特性値を用いて回答を生成し、最終的なRMSEの評価基準としていた。

実データ実験では真の特性値は観測できない。そのため、`person_scores.csv` の `theta_EAP` を参照能力値として使用する。

```text
theta_reference = person_scores.csv の theta_EAP
```

`theta_EAP` は全項目回答に基づくEAP推定値であり、真の能力値ではない。変数名、出力列、ログおよび本文では `theta_true` ではなく `theta_reference` または `theta_full_EAP` と表記する。

参照能力値は主に次の目的で使用する。

- テスト受験者におけるRMSEの計算
- MAE、bias、相関係数の計算
- 学習・検証中の診断用ログ

主実験の既存DQNと提案DQNでは、参照能力値を状態、回答生成、報酬、Qネットワークの入力には使用しない。

EXP001のシミュレーション学習では、潜在特性値は主としてIRTモデルによる回答生成に使用されている。実データ実験では回答行列から実回答を取得するため、回答生成用の潜在特性値は不要になる。

`fi_ref`、`err_reduction_ref`、`neg_sq_err_ref` など、参照能力値を必要とする報酬条件は主実験に含めない。これらを実行する場合は、全項目回答から得た情報を学習に使用する感度分析として明確に区別する。

## 10. 検証とモデル選択

学習途中で固定された検証受験者に対して、greedy方策によるCATを実行する。

最良モデルの選択基準はEXP001を引き継ぎ、各条件が定義する平均エピソード収益とする。

- 既存手法：`fi_hat_prev` に基づく平均収益
- 提案手法：`prec_gain` に基づく平均収益

検証受験者の `theta_reference` に対するRMSEは診断用として記録するが、最良モデルの選択には使用しない。

検証はエポック終了時に必ず実行する。必要に応じて、1エポック内の一定受験者数ごとにも実行可能とする。

## 11. 比較条件

主実験では次の条件を比較する。

- MFI
- FIWL
- MPWI
- MEPV
- existing
- proposed

同一反復内では、すべての条件で次を共通とする。

- 同一の項目パラメータ
- 同一のCAT候補項目
- 同一のテスト受験者
- 同一の実回答行列
- 同一の初期能力推定値
- 同一のMLE＋Dodd能力推定
- 同一のテスト長

DQN条件については、ネットワーク初期値、探索、ミニバッチ抽出を変えるため、データセットごとに10反復を実行する。反復ごとに受験者分割を切り替えるため、テスト受験者は反復間で共通ではない。

解析的項目選択規則は決定論的であるため、同一分割では1回のみ評価する。ただしテスト分割は反復ごとに再抽出するため、解析的規則の指標も反復ごとに記録し、DQN条件と同じ反復数で集計する。

## 12. テスト長

主実験のテスト長はEXP001と同じ40問とする。

## 13. 乱数管理

乱数種は用途ごとに分離する。

| 乱数種 | 用途 |
|---|---|
| `split_seed` | 学習・検証・テスト分割の基準値。反復kは `split_seed + k - 1` を使う |
| `shuffle_seed` | エポックごとの受験者順序 |
| `train_seed` | Qネットワーク初期値、探索、ミニバッチ抽出。反復kは `train_seed + k - 1` |
| `rep` | DQNの反復番号 |

同一反復内では受験者分割を固定し、手法間では `train_seed` のみを変える。反復間では分割用乱数種と `train_seed` の両方を反復番号に応じて変える。

同じ反復番号のexistingとproposedでは、可能な範囲で同じ学習受験者順序を使用する。ただし、`n_env` や探索過程の違いによって遷移系列が完全には一致しないことを許容する。
